# Evaluate generated tests

1. Confirm a fresh `playwright-quality-evaluator` context whose identity differs
   from the author context.
2. Validate the exact `playwright-test` revision, checksum, approved scenario,
   metadata, imports, and credential boundaries.
3. Run `npm run check:generated-tests` before any browser.
4. Inspect the layer-first taxonomy architecture and deliberate reuse.
5. Record sanitized evidence for every quality dimension.
6. Emit `PASS`, `REVISE`, or `BLOCKED` for the exact checksum. Never edit tests
   or infer approval.
