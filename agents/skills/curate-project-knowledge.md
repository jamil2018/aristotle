# Curate Project Knowledge

1. Begin only after an exact final human-review record exists.
2. Build a structured run summary from artifact references, transitions,
   decisions, feedback, metrics, and final disposition.
3. Apply configured retention and redaction; reject raw transcripts, secrets,
   authentication state, and unredacted personal data.
4. Freeze the accepted summary as immutable run history.
5. Extract only reusable lessons and scope each by feature, role, application
   area, environment, browser, artifact type, and failure signature.
6. Record evidence, confidence, and explicit invalidation conditions.
7. Submit the exact knowledge proposal for separate human approval.
8. Retrieve only approved, current, exact-scope entries and disclose every
   influence in the new output.
9. Keep retrieved knowledge advisory; current approved requirements remain
   authoritative.
10. Send recurring feedback to workflow improvement analysis only when its
    versioned threshold is met.
