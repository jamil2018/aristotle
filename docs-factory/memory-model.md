# Memory model

Memory begins only after exact final human review. Immutable run summaries
contain structured artifact references, outcomes, feedback, and metrics, never
raw transcripts or sensitive material. Knowledge proposals carry narrow scope,
evidence, confidence, and invalidation conditions.

Only separately human-approved, current, exact-scope knowledge is retrievable.
Its influence is disclosed and remains advisory. Policy adoption also requires a
distinct human approval, regression success, shadow evaluation success, and a
rollback plan.
